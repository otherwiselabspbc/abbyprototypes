Design Frameworks

11 skills
What is a skill?
A skill is a prompt document that instructs Claude how to approach a specific design task — like evaluating a game with the MDA framework or checking curriculum alignment. To invoke one, type its slash command (e.g. /mda) at the start of a message to Claude, and it will apply that skill's instructions to your work.
curriculum-mapping
Use before designing any mini-game to ensure it correctly targets a specific reading skill from the Lindamood Bell-informed curriculum.
/curriculum-mapping
explicit-instruction
Defines how instruction within each mini-game should be structured. Based on evidence-based reading curriculum principles (OG, Lindamood Bell).
/explicit-instruction
game-based-learning
Review or apply evidence-based game-based learning principles when designing, auditing, or iterating on any mini-game. Covers cognitive load, feedback, motivation.
/game-based-learning
game-storyboard
Use when designing a new mini-game from scratch. Provides the complete screen-by-screen structure every game must follow, including tutorial and sprint phases.
/game-storyboard
game-vision
Reference the core product vision, design principles, and three-phase roadmap for OL Prototypes before building any game or feature.
/game-vision
mda
Evaluate a game's effectiveness using the MDA Framework (Mechanics, Dynamics, Aesthetics). Use when auditing whether a mini-game achieves intended learning.
/mda
octalysis
Audit or design a game feature against the Octalysis Framework (Yu-kai Chou). Ensures the game engages all 8 Core Drives, balancing extrinsic and intrinsic motivation.
/octalysis
product-management
Manage the end-to-end design process for OL Prototypes. Covers design stages (Double Diamond), decision logging, user research, prototype handoffs.
/product-management
resources
Central library of all research sources, readings, and references used in the OL Prototypes design process. Search by topic, type, or keyword.
/resources
ui-ux
Review or apply UI/UX design principles to a game screen, component, or interaction. Covers general design principles plus literacy-specific accessibility.
/ui-ux
minigame-mechanics
Structure, pacing, and UI rules for sprint mini-games — short pop-up challenges (~20-30s) that test a single skill during longer play sessions.
/minigame-mechanics
